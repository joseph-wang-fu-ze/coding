# 盲旋转 / SampleExtract 实测（路线 B，2026-09-19）

> 依据：CAPE 论文 §2 的 FHE 子程序定义。环参数：N=16384、t=65537、
> 声明 9 素数/438 位、**工作层 8 素数/389 位**、base=2¹⁶、levels=25。

---

## 一、论文定义（原文）

> **BlindRotate(ct_L, ct_R) → ct'_R**：给定 LWE 加密 `ct_L ← LWE.Enc_s(r)` 与累加器
> `P(X) = Σ_{i=0}^{N−1} p_i X^i` 的 RLWE 加密，按**加密下标 r** 同态旋转累加器，
> 使 **p_r 被移到 ct'_R 的常数系数**上。

> **SampleExtract_j(ct_R) → ct_L**：给定 `ct_R ← RLWE.Enc_s(Σ m_i X^i)`，取出第 j 个系数，
> 输出 `ct_L ← LWE.Enc_s(m_j)`；必要时包含到后续计算所用 LWE 密钥的密钥切换。

> **Pack({ct_L,i}) → {ct_R,β}**：把一批 LWE 密文的消息打包进一个或多个 RLWE 密文。
> **LWEtoRGSW(ct_L) → C_μ**：把 μ ∈ {0,1} 的 LWE 密文转成 RGSW（用于查询压缩变体的选择器扩展）。

## 二、实现方式

要的就是 `Q(X) = X^{−r}·P(X)`（常数项恰为 p_r），而

```
X^{−r} = X^{−b} · X^{⟨a,s⟩} = X^{−b} · Π_i X^{a_i·s_i}
```

于是：

```
ACC ← P(X) 的密文
对每个 i:  ACC ← CMUX(BK_i, ACC, ACC·X^{a_i})   // s_i=0 不动；s_i=1 乘 X^{a_i}
ACC ← ACC · X^{−b}                              // 公开量，不需要密钥
```

- `BK_i = RGSW(s_i)`，而 `s_i ∈ {0,1}` 正是 `encryptRgswConstant` 支持的常数选择器，
  所以**自举密钥直接可用**（`LWEtoRGSW` 那条后续也能复用同一构造）。
- `X^{a_i}` 与 `X^{−b}` 用新增的 `Mpc4jRgsw.multiplyPowerOfX`：负循环环里
  `k ≥ N` 等价位整体取负再平移 `k−N`，平移跨过 `X^N` 的项再变号，两个条件异或定符号。
- **LWE 模数取 `q_L = 2N`**：这样密文系数 `a_i` 本身就是旋转指数，无需缩放对齐
  ——这正是 CAPE 把 LWE 模数定成 2N 的原因。

### ⚠️ 轮数口径的修正（2026-09-19，重要）

上面那套是**教科书 CGGI** 写法：按**秘密位**轮，共 **d** 轮，末尾补一次 `X^{−b}`。
但 Pirouette §4.1（CAPE 明确继承其参数化）用的是**按索引位**轮：

```
ct_k ← LWEtoRGSW(c̃t_k),  ∀k ∈ [0, log(N)−1]
{RGSW(idx_i)}_{i∈[0,⌈log2 N⌉−1]} 用作 CMUX 控制位
```

即 r = Σ z_i·2^i，于是 `X^{−r} = Π_i X^{−z_i·2^i}`，每轮

```
ACC ← CMUX(RGSW(z_i), ACC, ACC·X^{−2^i})        // 共 ⌈log₂N⌉ 轮，末尾不需要再补旋转
```

**两种口径数学等价**（`Σ a_i s_i − b ≡ −r`），但代价差 `d / ⌈log₂N⌉` 倍：

| | 口径 1：按索引位（论文结构） | 口径 2：按秘密位（教科书） |
|---|---|---|
| 轮数（N=16384） | **14** | 512 |
| 自举密钥 | **14 个 RGSW** | 512 个 RGSW |
| 自举密钥体积 | **700 MB**（ℓ=25 现状） | ≈ 25.6 GB |
| 盲旋转耗时 | **19.2 s**（实测） | ≈ 352 s（按 688 ms/CMUX 外推） |

两个口径都已实现（`blindRotateByBits` / `blindRotate`），并**互相验证结果一致** ✓。

## 四、密钥体积：从"红线"降级为"可优化项"

修正口径后，自举密钥是 **14 个 RGSW ≈ 700 MB**（而非原先按 d=512 估的 25.6 GB），已在可控范围。

剩下的 3 倍收缩空间来自 `levels`。**50 MB/个**的体积源于 `levels = 25`：底 B=2¹⁶ 受限于
"数字必须以明文形式喂进 `multiplyPlain`"，而明文的 fast plain lift 窗口只有
`±t/2 = ±32768`（见 `Mpc4jRgsw.decompose` 注释），故 B ≤ t、层数被迫取 `⌈389/16⌉ = 25`。
而 Pirouette Table 4 给的是 **B_rgsw = 2²⁴、ℓ_rgsw = 8**——底远超明文窗口，
说明它必然走直接/RNS 法（见 `CAPE_参数表.md`）。

| 手段 | levels | 每个 RGSW | 自举密钥（14 个） |
|---|---|---|---|
| 现状：明文切段、底 B=2¹⁶ | 25 | 50 MB | 700 MB |
| **RNS/直接切段**（对齐 Pirouette 的 ℓ_rgsw = 8） | **8** | ≈ 16 MB | **≈ 224 MB** |
| 缩小 d | — | — | **不影响口径 1 的体积**（只与 ⌈log₂N⌉ 有关） |
